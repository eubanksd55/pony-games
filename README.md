# Pony Letters

Single-file HTML game, hosted on GitHub Pages: https://eubanksd55.github.io/ponyletters/

## Updating

Edit `index.html`, then run `./deploy.sh "your message"` (or `sh deploy.sh`). Pages redeploys from `main` in about a minute.

## iOS home-screen note

iOS caches home-screen web apps aggressively. After an update, if the icon still opens the old version, delete the icon and re-add it from Safari (Share > Add to Home Screen).
